# Finer axial interval subdivision

The original six reference JSONs remain unchanged. These additional recipes
change how the retained axis interval is divided, reducing the large central
copies while preserving all geometric inclusion and linking arguments.

For integer M>=2 replace the two axial maps by

    a_j(x) = (1/M) R_u(theta_j)x + ((2j+1-M)/M) B,
    tan(theta_j/2) = a (2j+1-M)/(M-1),    j=0,...,M-1,

where B=(1,1,1), u=B/sqrt(3), and a=1/3 in these variants. The images of
[−B,B] are exactly the consecutive M equal closed subintervals covering it.
Every rotation is around the C3 axis, so covariance and symmetry persist.
The ring and bridge maps are unchanged. The central scale q is separately
specified as a rational number.

The new covering equation is

    M^(1-s) + 39m (1/(2m sqrt(3)))^s + 4q^s = 1.

It supplies an upper bound, not an asserted exact Hausdorff dimension.

| m | M | q | Maps | Numerical covering root | Exact certified strict dim_H bound |
|---:|---:|---:|---:|---:|---:|
| 3 | 3 | 1/8 | 124 | 2.19349557 | 11/5 |
| 3 | 4 | 1/8 | 125 | 2.15527765 | 13/6 |
| 3 | 6 | 1/8 | 127 | 2.12049925 | 17/8 |
| 2 | 4 | 3/20 | 86 | 2.36363949 | 12/5 |
| 1 | 6 | 1/8 | 49 | 2.97899948 | 3 |

All have zero volume, exact C3 symmetry, the literal Borromean skeleton,
and every-scale solid-ball tangents at the dense set of cylinder centres.
Invariant radius 5/2 suffices for m>=2; the denser m=1 variants use radius3.

The first four are generated by `axis_variants.py`; their exact scalar
certificates are in `axis-variants-exact-certificate.json`. The 49-map dense
extreme is generated by `dense_variants.py` at edge roll half-tangents0,
1/2, and1, with certificates in `dense-variants-exact-certificate.json`.
The certificate uses only rational arithmetic and integer root bounds.

The finite point comparison favours m3/M6/q1/8 for visibly open passages;
the m1 variants look much fuller, with most openings obscured at that
sampling/display scale. This is subjective visual screening, not a theorem
about complement topology or a final aesthetic selection.

with every scaled-orthogonality equation checked exactly and numerical
agreement with the JSON implementation below 2.3e-16. Native IFStile import
is to be assessed separately by root.

```powershell
uv run --python 3.12 --with numpy python fractal_discovery_2026/survey/axis_variants.py
uv run --python 3.12 --with numpy --with moderngl --with pillow python fractal_discovery_2026/survey/render.py --summary axis-variants-summary.json --sheet axis-variants-sheet.jpg
```
